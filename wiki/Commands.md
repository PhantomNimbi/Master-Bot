# 📜 Commands Reference Hub

Master-Bot provides **74 production slash commands** organized across 4 primary categories.

---

## 📚 Command Categories

- [🎵 **Music & Playlist Commands**](Commands-Music): Playback, queue controls, playlists, audio filters, music trivia.
- [🔨 **Moderation Commands**](Commands-Moderation): Ban, kick, purge, slowmode, timeout with permission checks.
- [🎮 **Utility & Fun Commands**](Commands-Utility): Polls, reminders, weather, news, game search, TV search, mini-games, GIFs.
- [⚙️ **Server Configuration (`/set`)**](Commands-Server-Settings): Guild configuration for audit logs, tickets, welcome messages, suggestions, verification.
